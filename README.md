# ClipKeep

A small clipboard history app for the macOS menu bar. It remembers the text you copy, lets you search it, and copies any entry back with one click. History is stored in a local JSON file: no database, no cloud.

## Features

- Menu bar only (no Dock icon)
- Global hotkey **⌘⇧V** to open the history
- Search by any words in the text or the source app name, case-insensitive
- Copying the same text again moves it to the top instead of duplicating it
- Keeps the latest 500 clips
- Skips clips that password managers mark as private ([nspasteboard.org](http://nspasteboard.org) `ConcealedType`, `TransientType`, `AutoGeneratedType`)

## Requirements

- macOS 13 or later
- Xcode or Command Line Tools with Swift 5.10+

## Run

```bash
swift run
```

Or open `Package.swift` in Xcode and press ⌘R.

The app runs in the menu bar: click the 📋 icon or press ⌘⇧V. Only one instance should run at a time, or the hotkey will clash (`pkill ClipKeep` stops a running copy).

## Build the app

```bash
./build-app.sh             # creates dist/ClipKeep.app
./build-app.sh --install   # also copies it to ~/Applications
```

The app is ad-hoc signed, so it runs on this Mac but isn't set up for distribution to others (that needs a Developer ID and notarization). To start it at login, add it under System Settings › General › Login Items.

## Test

```bash
swift run ClipKeep --selftest   # prints "selftest ok"
```

## Where data is stored

```
~/Library/Application Support/ClipKeep/history.json
```

The file is readable only by your user (`0600`) but is **not encrypted**. Text you copy by hand, including passwords, is saved unless the source app marks it as concealed. Use **Clear** in the app or delete the file to wipe history.

## Project layout

| Path | Purpose |
| --- | --- |
| `Sources/ClipKeep/ClipKeep.swift` | Clipboard monitor, menu bar item, popover UI, self-test |
| `Sources/ClipKeep/History.swift` | History logic (dedupe, limit, search) and the JSON file store |
| `Sources/ClipKeep/HotKey.swift` | Global hotkey via Carbon `RegisterEventHotKey` (no Accessibility permission needed) |
| `build-app.sh` | Builds and signs `dist/ClipKeep.app` |
| `make-icon.swift` / `AppIcon.icns` | App icon generator and its output |

## How it works

macOS has no "clipboard changed" notification, so ClipKeep polls `NSPasteboard.general.changeCount` every 0.5 s and reads the clipboard only when the count changes. Each change saves the whole history file again with an atomic write.

## Customizing

- **Hotkey:** edit `Combo.default` in `HotKey.swift`.
- **History size:** edit `History.limit` in `History.swift`.
- **Icon:** edit the colors or the SF Symbol name in `make-icon.swift`, then run `swift make-icon.swift && ./build-app.sh`.

## Limitations

- Text only; images, files and rich text aren't stored yet.
- The whole file is rewritten on every copy. That's fine for 500 text clips; for much larger histories, switch to an append-only format.
